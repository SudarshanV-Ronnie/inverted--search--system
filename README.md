# 🔍 Inverted Search System

An efficient **Inverted Search Engine** developed using **C Programming** and **Data Structures** to perform fast word searching across multiple text files.

This project builds an inverted index database for efficient searching, updating, and storage of file contents.

---

# 📌 Project Overview

The Inverted Search System indexes words from multiple files and stores them in a structured database format for quick retrieval.

Instead of searching entire files repeatedly, the system creates an **inverted index**, making search operations significantly faster.

---

# 🚀 Features

✅ Create database from text files
✅ Display indexed database
✅ Update database dynamically
✅ Search words instantly
✅ Save database backup
✅ Multiple file handling
✅ Linked List implementation
✅ Hash table based indexing

# ⚙️ Functionalities

## 1️⃣ Create Database

Reads words from input files and creates an inverted index database.

## 2️⃣ Display Database

Displays indexed words along with:

* File names
* Word count
* File occurrence count

## 3️⃣ Update Database

Allows adding new files dynamically into the existing database.

## 4️⃣ Search Operation

Searches for a given word and displays:

* File names
* Number of occurrences

## 5️⃣ Save Database

Stores indexed database into a backup file.
